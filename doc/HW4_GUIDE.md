# 作业：电机模型辨识（对应《4.3 电机模型辨识测试作业》）

> 对象：STM32F103C8T6 + TB6612FNG 双电机小车（本仓库）
> 交的东西：一张**填空式报告页**——4 个二阶传递函数 + 2 组内部参数 + 「异常位置及复测方案」

---

## 0. 一句话

不是新实验台，而是**把已经能转、能测速的左/右电机再拿来做一次参数辨识**：
先把「占空比 → 电机两端真实平均电压」标定出来，再给电压阶跃、串口录转速曲线，
用 MATLAB 拟合 `电压 → 转速` 的**二阶传递函数**；结合万用表/LCR 测出的 `Ra`、`La`
和手册算出的 `K`，反推出内部参数 `J`、`B`。

**要填的四组模型**（少一组就少一半分）：

| # | 位置 | 填什么 |
|---|---|---|
| 1 | 左电机（不带车轮） | `Ra` `La` 减速比 `Ke` `Kt` `J` `B` + 二阶传递函数 |
| 2 | 左电机（带车轮试验） | 只有二阶传递函数（`J`、`B` 变了） |
| 3 | 右电机（不带车轮） | 同 1 |
| 4 | 右电机（带车轮试验） | 同 2 |

## 1. 要用到的公式

### 1.1 二阶传递函数（被控量：输出轴角速度 rad/s）

```
              Kt
G(s) = ─────────────────────────────────────
        La·J·s² + (La·B + Ra·J)·s + (Ra·B + Ke·Kt)
```

有刷直流电机 `Ke ≈ Kt ≈ K`，所以分母常数项是 `Ra·B + K²`。

分子化到首一形式：

```
              b0
G(s) = ─────────────────        b0 = Kt/(La·J)
        s² + a1·s + a0          a1 = B/J + Ra/La
                                a0 = (Ra·B + K²)/(La·J)
```

### 1.2 空载法算 K（文档里那个公式对象就是它）

```
        U₀ − Ra·I₀
K  =  ──────────────
            ω₀
```

- `U₀` 空载电压、`I₀` 空载电流、`ω₀` 空载角速度 —— 三个都查**产品手册**
- 手册给的转速通常是输出轴 rpm：`ω₀ [rad/s] = n₀ [rpm] × 2π/60`
- 本车手册标注空载 366 rpm；**必须自己翻手册核对**，并且注意它是电机轴还是输出轴

### 1.3 反算 J、B（这是本题的"内部参数"部分）

黑箱拟合得到 `G(s) = b0/(s² + a1·s + a0)`，再拿实测 `Ra`、`La` 和手册 `K`：

```
J = Kt / (La · b0)
B = J · (a1 − Ra/La)
校核：a0 ?= (Ra·B + K²)/(La·J)     ← 对不上说明数据或单位有问题
```

`a0` 校核还能反推一个 `K`，和 1.2 的 `K` 对比，差太多要回头查。

## 2. 六步流程

| 步 | 干什么 | 工具 | 产出 |
|---|---|---|---|
| 1 | 两路电机 + 两路编码器都确认能转、能计数 | 现有固件 | 右编码器（PA15/PB3）先验证 |
| 2 | 测 `Ra`、`La` | 万用表 / LCR 电桥 | 左右各一组 |
| 3 | 标定：占空比 ↔ 电机两端平均电压 | 万用表 DC / 示波器均值 | `U = a·duty + b` |
| 4 | 电压阶跃 + 串口录转速曲线 | 新加的阶跃测试模式 | CSV：`t, duty, rpm` |
| 5 | 拟合二阶传递函数 | MATLAB `tfest` / `iddata` | 4 个 `G(s)` |
| 6 | 反算 `J`、`B`，填表 | 计算器 / 脚本 | 报告页 |

### 第 2 步：Ra、La 怎么测

- `Ra`：电机**脱开驱动板**，万用表两线测电枢两端。转子转几个角度多测几次取平均
  （电刷换向会造成 ±几 % 波动）。注意别把驱动器内阻算进去。
- `La`：LCR 电桥在 1 kHz 左右测电枢两端。没有电桥就用电枢阶跃电流法：
  给一个方波电压，用示波器看电流上升段，`τe = La/Ra`，`La = τe·Ra`。
- **左右电机分开测**，文档明确说参数会有差异。

### 第 3 步：驱动压降标定（最容易漏的一步）

TB6612 输出不是理想开关：`U_arm = duty·VM − ΔU`，`ΔU` 随电流变。

做法：

1. 固定 `VM`（用稳压电源并记下读数，别用快没电的电池）。
2. 占空比取 `20/40/60/80/100 %`，每个点让电机**稳定运行**（不是堵转）。
3. 万用表 DC 档量电机两端（AO1–AO2 / BO1–BO2）的平均电压，记录。
4. 线性拟合 `U_arm = a·duty + b`，得到这条"标定线"。
5. 左、右通道**分开标定**（不同 TB6612 通道、不同线损）。

> 后面所有实验里，模型的**输入是 `U_arm`（伏特），不是占空比**。

### 第 4 步：阶跃实验

- 阶跃幅度：`0 → 60%~80%` 占空比（太低会卡在静摩擦死区，非线性，拟合会不准）。
- 采样率：**现在固件的 100 ms 太慢**，二阶系统快极点可能几十 ms。改到 **10 ms（100 Hz）**。
- 每次阶跃至少录 1~2 s（等转速稳定到平台）。
- 每种配置录 **3~5 次**，取重复性好的，避免单次噪声。
- 记录实验时的 `VM` 和电流方向（正转）。

### 第 5 步：MATLAB 拟合

```matlab
% data: 第 1 列 t(s)，第 2 列 U(V)，第 3 列 rpm
u  = data(:,2) - data(1,2);          % 去掉稳态偏置
w  = data(:,3) * 2*pi/60;            % rpm -> rad/s（输出轴）
Ts = mean(diff(data(:,1)));
dat = iddata(w, u, Ts);
opt = tfestOptions('WeightingFilter','auto');
sys = tfest(dat, 2, 0, opt);         % 二阶、无零点
[wk, wc] = dcgain(sys);              % 校核稳态增益
zpk(sys)                             % 看极点实虚部
```

没有 System Identification Toolbox 就用最小二乘：对 `s²+a1 s+a0` 解线性方程，
或直接对阶跃响应做 `lsqcurvefit` 拟合 `J`、`B` 两个参数。

### 第 6 步：反算 + 填表

按 1.3 的公式算 `J`、`B`，然后：

- "二阶传递函数模型为：" 填**数值化**的 `G(s)`，例如
  `G(s) = 12.6/(0.00042 s² + 0.013 s + 1.02)`
- "带车轮"那组：`Ra`、`La`、`K` 不变，只有 `J`、`B` 和 `G(s)` 变
- 全部统一到**同一轴侧（输出轴/车轮轴）**、转速单位 **rad/s**

## 3. 固件要补什么

当前 `main.c` 是"左右电机 20% 起步一起正转 + PA5 按键分档调速（左右同档） + 100 ms 输出 L/R 双字段"的调试版，
**没有阶跃测试模式，也没有 10 ms 采样**。需要新增一个模式，要点：

```c
/* 阶跃测试（放 main.c USER CODE 2 / 3 区） */
static const uint8_t  STEP_DUTY   = 70;      /* 阶跃目标占空比 % */
static const uint32_t STEP_AT_MS  = 1000;    /* 上电 1 s 后施加阶跃 */
static const uint32_t SAMPLE_MS   = 10;      /* 10 ms 采样 → 100 Hz */

uint32_t t0 = HAL_GetTick();
int32_t  last_L = 0;
Motor_SetDirSpeed(left_motor, MOTOR_DIR_FORWARD, 0);      /* 先停 */
Motor_SetDirSpeed(right_motor, MOTOR_DIR_STOP, 0);

while (1) {
    uint32_t now = HAL_GetTick();
    if (now - t0 >= STEP_AT_MS) {
        Motor_SetDirSpeed(left_motor, MOTOR_DIR_FORWARD, STEP_DUTY);  /* ← 阶跃 */
    }
    if (now - t0 >= last_out + SAMPLE_MS) {                 /* 10 ms 输出一次 */
        int32_t c = Motor_GetCount(left_motor);            /* 累计计数 */
        /* rpm_x10 用当前窗口计数增量算，注意低速量化误差 */
        printf("%lu,%d,%ld\r\n", now - t0, duty_now, rpm_x10);
        last_out = now - t0;
    }
    Motor_Update(left_motor);
    Motor_Update(right_motor);
    HAL_Delay(1);
}
```

注意：

1. **低速量化**：10 ms 内转速 300 rpm 只有 78 个计数，够用；刚起步那几毫秒只有几个计数，
   噪声大。要么用定周期计数做滑动平均，要么阶跃目标别太低。
2. **左右分开录**：一次只跑一个电机，另一个 `MOTOR_DIR_STOP` + 占空比 0。
3. 时间戳用 `HAL_GetTick()`（1 ms 分辨率），别用 `HAL_Delay` 累加。
4. 输出行建议 `t_ms,duty,L_count,R_count`，转速在 MATLAB 里算，别在 MCU 里算，
   这样原始数据可复用。

## 4. 单位与口径（文档专门警告了，最容易失分）

| 项 | 要求 |
|---|---|
| 转速单位 | **rad/s**，`ω = rpm × 2π/60` |
| 轴侧 | 辨识用的转速、算内部参数用的转速，**必须是同一根轴**（建议都用输出轴） |
| 折算 | 若用输出轴：`K_out = 30·K_motor`、`J_out`、`B_out` 都折算到输出轴，三处必须一致 |
| 本项目 | 编码器 13 PPR × 30:1 × 4 倍频 = **1560 计数/圈（车轮圈）** |
| 减速比 | 填 **30**（可用 1560/(13×4) 反算验证） |
| 模型含什么 | 带车轮那组，模型**显式包含齿轮箱 + 车轮**的等效惯量，报告里要写清楚 |

## 5. 「异常位置及复测方案」参考写法

如果数据正常：

> 左右电机各自阶跃响应重复性良好，辨识模型与实测曲线残差小于 5%，`a0` 校核与 `Ra·B+K²`
> 一致。右轮编码器曾因 A 相线路接触不良导致计数缺失，已改用 PA15/PB3 并复测通过。
> 复测顺序：先确认两路编码器手转计数正常 → 再验驱动标定线 → 最后做阶跃采集。

如果某一步对不上，写清楚**现象 + 原因 + 复测方案**，例如：

> 右电机辨识增益偏高约 12%。检查发现右通道标定时用旧电池，`VM` 掉压至 10.4 V，
> 标定线 `a` 偏小。更换稳压电源后重新标定并复采，增益偏差降到 3% 以内。
